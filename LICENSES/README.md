The complete license texts and brand policy are stored in this directory. The repository root `LICENSE` contains the primary license for GitHub detection and convenient access. When a repository contains more than one category of material, this document defines the category boundaries.

## Scope rules

1. A file-specific license notice or SPDX identifier takes priority over this document.
2. Third-party material remains subject to its original license and attribution notice.
3. Hardware includes schematics, PCB layouts, editable EDA sources, Gerber data, BOMs, placement data, mechanical design files, and other files explicitly identified as hardware design material.
4. Software includes source code, scripts, firmware, libraries, tests, and build configuration explicitly identified as software.
5. Documentation includes prose, specifications, tutorials, and diagrams, unless a file-specific notice says otherwise.
6. Generated output is governed according to the source material and any notice included with the output.
7. The open licenses do not grant permission to use CraftVia brand assets. Descriptive references and compatibility statements are governed by the CraftVia Trademark Policy.

A suitable attribution is:

> CraftVia documentation, copyright Kohei Ikeda, licensed under CC BY 4.0.

Where practical, link “CraftVia documentation” to the original material and “CC BY 4.0” to <https://creativecommons.org/licenses/by/4.0/>. Indicate if changes were made.
